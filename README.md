# Zeenat S. — Sovereign Trade & Diplomacy Portfolio

A high-fidelity, institutional-grade executive portfolio and diplomatic trade portal built with React 19, Vite, and Tailwind CSS.

## 🚀 Key Features

- **Executive & Diplomatic Presentation**: High-level ministerial and cross-border trade presentation.
- **Dynamic Hash Routing**: Zero-refresh smooth tab navigation compatible with all static hosting providers (GitHub Pages, Vercel, Netlify).
- **Interactive Modals**: VIP Portal, Strategic Collaboration Desk, Investor Lead Desk, Media Kit, and Admin CMS.
- **Automated Deployment**: Pre-configured GitHub Actions workflow for zero-configuration GitHub Pages publishing.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 📦 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 GitHub Pages Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the site to GitHub Pages on every push to `main`.

1. Go to your repository on GitHub: `https://github.com/Ashutoshkuma8271/Portfolionew`
2. Navigate to **Settings** > **Pages**
3. Under **Build and deployment** > **Source**, select **GitHub Actions**
4. Push your changes to `main` — the website will be deployed automatically without blank page errors!
