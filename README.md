# Zeenat S. — Sovereign Trade & Diplomacy Portfolio

A high-fidelity, institutional-grade executive portfolio and diplomatic trade portal built with React 19, Vite, and Tailwind CSS.

## 🚀 Key Features

- **Executive & Diplomatic Presentation**: High-level ministerial and cross-border trade presentation.
- **Dynamic Hash Routing**: Zero-refresh smooth tab navigation compatible with all static hosting providers (GitHub Pages, Vercel, Netlify).
- **Interactive Modals**: VIP Portal, Strategic Collaboration Desk, Investor Lead Desk, Media Kit, and Admin CMS.
- **Automated Deployment**: Pre-configured GitHub Actions workflow for zero-configuration GitHub Pages publishing.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 📦 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Production Deployment

This project is optimized for deployment on **Vercel**, **Netlify**, or any modern static hosting platform with zero configuration.

### Vercel Deployment (Recommended)
1. Import this repository into [Vercel](https://vercel.com).
2. Framework preset: **Vite**
3. Build command: `npm run build`
4. Output directory: `dist`
5. Connect your custom domain `zeenatkureshi.com` in Project Settings.
